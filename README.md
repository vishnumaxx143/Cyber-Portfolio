# Vishnu Vardhan J — Cybersecurity Student Portfolio

A responsive, dark cybersecurity-themed portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio content and sections
- `style.css` — layout, responsive styles and neon-green theme
- `script.js` — mobile navigation, active section link and current year
- `portfolio-preview.png` — generated visual concept preview (not the live site)

## Run locally
Open `index.html` in a browser, or open the folder in Visual Studio Code and use the Live Server extension.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `vishnumaxx143.github.io` (this name is the user site URL format for that GitHub username).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under build/deployment, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for GitHub Pages to deploy, then visit `https://vishnumaxx143.github.io/`.

If that repository name is unavailable or you prefer a project repository, use a different repository name and follow the Pages URL GitHub displays in Settings → Pages.
